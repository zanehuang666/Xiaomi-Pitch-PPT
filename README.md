# GitHub Pages 发布文件

此文件夹含：
- `index.html`：无需登录即可阅读的 5 页文字版网页
- `笔试草稿-V1.pptx`：原始演示文稿下载文件
- `.nojekyll`：GitHub Pages 配置文件

建议在 GitHub 账号 `zanehuang666` 下新建**公开**仓库 `temasek-ppt`，把上述三个文件上传到仓库根目录。然后在仓库 Settings → Pages 中选择 **Deploy from a branch**、`main`、`/(root)` 并保存。发布完成后，网页地址通常是：

https://zanehuang666.github.io/temasek-ppt/

请在另一台电脑使用无痕窗口打开该地址，确认 5 页内容和“下载原始 PPT”链接都能使用。

公开仓库和网页会公开这些文件的全部内容。如果考试规则禁止查阅资料，应遵守规则。
